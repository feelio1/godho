# 펫병원체크 (PetClinicCheck)

동물병원 방문 전, 공개된 행정·인허가 정보를 확인하는 팩트체크 앱입니다.
병원을 평가·판정하지 않고, 보호자가 스스로 판단할 수 있도록 공공데이터 사실만 보여줍니다.
자세한 원칙과 워딩 규칙은 `CLAUDE.md`를 참고하세요.

## 시작하기

```bash
flutter pub get
flutter run
```

### 카카오맵 연동 (선택)

카카오 개발자 사이트에서 발급받은 **네이티브 앱 키**가 있다면 아래처럼 전달하세요.
없어도 앱은 정상 빌드되며, '주변 병원' 탭은 준비 중 화면으로 대체됩니다(지도 인증에 실패해도
같은 화면으로 안전하게 전환됩니다).

```bash
flutter run --dart-define=KAKAO_NATIVE_KEY=발급받은_네이티브_앱_키
```

### 애드몹 연동 (선택)

배너·앱 오프닝 광고 단위 ID는 `--dart-define`으로 주입합니다. 지정하지 않으면 구글이 공식
문서에서 공개한 **테스트 광고 단위 ID**로 자동 대체되어, 키 없이도 앱이 정상 빌드·실행되고
테스트 광고가 표시됩니다. 실제 서비스에는 반드시 본인의 광고 단위 ID로 교체하세요.

```bash
flutter run \
  --dart-define=ADMOB_BANNER_UNIT_ID=발급받은_배너_광고_단위_ID \
  --dart-define=ADMOB_APP_OPEN_UNIT_ID=발급받은_앱오프닝_광고_단위_ID
```

애드몹 **App ID**는 Dart 코드가 아니라 AndroidManifest 값이라 dart-define으로 줄 수 없습니다.
대신 `android/secrets.properties.example`을 `android/secrets.properties`로 복사하고(이
파일은 `.gitignore` 처리되어 커밋되지 않습니다) `ADMOB_APP_ID`에 실제 값을 채워넣으세요.
값을 채우지 않으면 역시 구글의 공개 테스트 App ID로 자동 대체됩니다.

하단 배너 광고는 홈·검색·상세·저장·주변 병원 화면 하단에 항상 노출되며, 앱 오프닝 광고는
마지막 노출로부터 4시간이 지난 뒤 앱을 다시 포그라운드로 가져올 때만(콜드 스타트·로딩 중 제외)
미리 로드된 경우에 한해 표시됩니다.

## 데이터

`assets/hospitals.json`은 전국 동물병원 인허가 데이터 번들입니다(약 10,584곳). 앱 시작 시 한 번
로드되어 메모리에서 검색·필터링됩니다 (서버·계정 없음). 지역(시/도·시군구) 목록은 이 데이터에서
동적으로 추출되며 하드코딩하지 않습니다.

## 지정 병원 · 진료기록 탭

- 병원 상세 화면 헤더에서 "지정 병원으로 등록" 칩을 눌러 병원을 "지정(단골)"으로 등록/해제할
  수 있습니다. 저장(♡)과는 줄을 분리해 둔 별개 기능이라 헷갈리지 않고, 누르면 스낵바로 등록·해제
  여부를 바로 알려줍니다. 지정한 병원은 홈 상단 "지정 병원" 섹션에 카드로 뜨고, 카드에서 바로
  전화·길찾기·상세보기가 가능합니다. 영업시간·실시간 영업여부는 표시하지 않습니다(데이터 없음 —
  확인이 필요하면 상세의 외부 링크로 안내). 전화 버튼은 상세·지정 병원·비교 화면 어디서나
  `ExternalLinks.call` 한 곳을 거칩니다 — 등록된 번호가 없거나 형식이 깨져 걸 수 없으면 조용히
  아무 반응이 없는 대신 스낵바로 안내합니다.
- 하단 탭 "진료기록"에서 반려동물 프로필과 진료 기록·다가오는 예약을 관리합니다. 이름·종·품종·
  생일·사진을 등록하고, 방문할 때마다 날짜·병원(검색해서 선택하거나 직접 입력)·메모·몸무게·
  진료비·사진을 기록으로 남길 수 있습니다. 기록 개수·총 진료비·최근 몸무게만 텍스트로 요약하며,
  그래프나 "비만/정상" 같은 판정은 제공하지 않습니다(CLAUDE.md 평가 금지 원칙).
- 같은 탭에서 진료 예약도 등록할 수 있습니다. 예약마다 "며칠 전 + 몇 시"로 알림을 원하는 만큼
  추가할 수 있고(예: 전날 저녁 + 당일 아침), 그 시각에 기기 로컬 알림이 울립니다. 알림 권한(및
  정확한 시각 알람 권한)은 예약에 알림을 처음 추가해 저장하는 시점에만 요청하며, 정확한 시각
  권한이 허용되어 있으면 지정 시각에 정확히, 없으면 근사 시각으로 자동 대체되어 울립니다. 권한을
  거부하거나 알림 기능을 쓸 수 없는 기기에서도 앱은 항상 정상 동작합니다(예약 기록 자체는 알림과
  무관하게 남습니다). 실제로 알림이 오는지 확인하고 싶다면 홈 우측 상단 메뉴 → 설정에서 "1분 뒤
  테스트 알림 보내기"로 바로 확인할 수 있습니다.
- 이 기록은 계정·서버 없이 기기에만 저장됩니다(SharedPreferences) — 앱을 지우거나 기기를
  바꾸면 사라질 수 있다는 안내가 화면에 항상 표시됩니다. 데이터 모델(Pet/MedicalRecord/
  Appointment)은 순수 클래스 + JSON 직렬화로 분리되어 있어, 추후 로그인·클라우드 동기화가
  추가되어도 저장소만 교체하면 됩니다.

## 지역·위치

- 홈/검색 화면 상단의 지역 표시를 눌러 시/도 → 시군구를 선택할 수 있고, 선택은 앱 재실행 후에도
  유지됩니다.
- 위치 권한은 "내 주변 병원" 버튼/탭을 최초 사용할 때만 요청합니다. 이미 허용된 상태라면 이후
  실행부터는 별도 요청 없이 조용히 위치를 사용해 지역과 정렬을 자동으로 맞춥니다. 사용자가 지역을
  직접 선택하면 그 선택이 GPS 기반 자동 선택보다 항상 우선합니다.
- 검색 결과는 기본적으로 영업중 병원만 표시하며, "폐업 병원도 보기"를 켜면 폐업 기록도 함께 나옵니다.
  단, 병원 상세 화면의 동일 주소 타임라인에는 이 필터와 무관하게 항상 모든 기록이 표시됩니다.

## 디자인 시스템 · 마스코트

- 브랜드 톤은 민트/세이지 그린(`AppColors.primary`) + 따뜻한 회갈색 텍스트(`AppColors.textPrimary`,
  장구름 캐릭터와 어울리는 배색)입니다. 모든 색상은 `lib/theme/app_colors.dart` 토큰만 사용합니다
  (하드코딩 금지). 화면 스타일은 `lib/theme/app_theme.dart`가 만드는 `ThemeData` 하나로 통일되어
  있으니, 새 화면은 `Theme.of(context)` 값을 그대로 쓰면 됩니다.
- 폐업은 빨강이 아니라 회색(`AppColors.closed`)입니다 — 평가가 아니라 인허가 기록상 사실일
  뿐이라는 뜻입니다(CLAUDE.md 평가 금지 원칙). 빨강(`AppColors.error`)은 데이터 로드 실패 같은
  실제 시스템 오류에만 쓰고, 폐업 색과는 완전히 분리된 값입니다.
- 마스코트 "장구름"은 `lib/widgets/mascot_image.dart`(`MascotImage`)가 담당합니다.
  `assets/mascot/`에 등록된 장구름 그림 중 상황에 맞는 것을 `assetPath`로 골라 쓸 수 있고
  (기본은 `janggureum.png`), 이미지가 없으면 조용히 아이콘 placeholder로 대체됩니다. 검색 결과
  없음은 `empty_search.png`, 진료기록·저장이 비어 있을 때는 `empty_record.png`를 씁니다. 마스코트는
  홈 배너·빈 상태·로딩·지도 준비중 화면처럼 친근함이 필요한 자리에만 쓰고, 병원 상세의 팩트카드·
  타임라인·진료비처럼 신뢰가 중요한 데이터 영역에는 넣지 않습니다.
- 병원 사진은 실제로 수집하지 않습니다(크롤링 금지) — `lib/widgets/hospital_thumbnail.dart`
  (`HospitalThumbnail`)가 모든 병원에 동일한 `hospital_placeholder.png`를 보여줘, 어떤 병원의
  사진이 있고 없고로 인상이 갈리지 않게 합니다.
- 병원 상세의 "예약하기" 버튼은 아직 실제 예약 연동이 없는 자리 예약용입니다. 누르면 특정
  병원과 제휴·거래 관계가 없다는 점을 알리는 안내만 뜹니다.

## 주변 병원 지도

- 마커는 캐릭터(장구름) 이미지 자리입니다. 실제 이미지가 없어 지금은 중립 placeholder
  아이콘을 쓰고, `assets/mascot/marker.png`를 추가해 pubspec.yaml에 등록하면 코드 변경 없이
  그 이미지로 자동 교체됩니다(마스코트와 동일한 패턴). 병원 이름 라벨은 개별 마커가 보이는
  줌 레벨과 같은 시점에 함께 노출되어, 겹침은 막으면서도 너무 늦게 나타나지 않습니다.
- 마커는 영업 상태와 무관하게 모두 같은 외형입니다 — 지도 위 색으로 병원을 구분하지 않습니다
  (CLAUDE.md 평가 금지 원칙). 상태·운영기간 같은 사실은 마커를 탭했을 때 나오는 하단 카드와
  상세 화면에서 그대로 확인할 수 있습니다.
- 카카오맵 SDK 자체에는 클러스터링 기능이 없어, `lib/utils/map_clustering.dart`에서 줌
  레벨에 따라 격자 크기를 바꿔가며 가까운 병원들을 직접 묶습니다. 격자 크기는 줌아웃할수록
  상한 없이 계속 커지도록 만들어, 아무리 멀리 축소해도 클러스터 개수("N")나 개별 마커 중
  하나는 항상 화면에 보입니다. 탭하면 확대되며 개별 마커로 풀립니다.
- 내 위치는 표준 파란 점이 아니라 마스코트(장구름) 자리에 후광을 두른 전용 placeholder로
  표시되어 병원 마커와 한눈에 구분됩니다. 지도 우하단의 버튼으로 현재 위치로 이동할 수
  있습니다. 위치 권한이 없으면 버튼을 눌렀을 때 권한을 요청하고, 그래도 위치를 알 수 없으면
  안내만 뜨고 앱은 정상 동작합니다.

## 폴더 구조

- `lib/models` — Hospital, Timeline, Pet, MedicalRecord, Appointment 등 데이터 모델
- `lib/data` — 번들 로더, 저장소, 로컬 저장(SharedPreferences)
- `lib/providers` — Riverpod 프로바이더
- `lib/notifications` — 진료 예약 로컬 알림(`flutter_local_notifications`) 서비스
- `lib/screens` — 홈/검색/상세/주변 병원/진료기록/저장/비교 화면
- `lib/theme` — 색상 토큰(AppColors)과 전역 ThemeData(AppTheme)
- `lib/utils` — 외부 링크, 지도 클러스터링 등 화면에 종속되지 않는 유틸리티
- `lib/widgets` — 공용 위젯 (팩트카드, 타임라인, 진료비 섹션, 마스코트, 병원 검색 필드, 사진 첨부 필드 등)
