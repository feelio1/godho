# 스프린트 2 지시서 — 펫병원체크

목표: 인천 전용에서 **전국**으로 확장. 지역 선택 + GPS 위치 + 검색 영업중 기본 필터 추가. 디자인 개선은 이번 스프린트 범위 아님(기능만).

전제: assets/hospitals.json이 전국 번들(약 10,584곳)로 교체됨. CLAUDE.md의 원칙·워딩·스키마 준수. 상태관리 Riverpod 유지.

---

## 1. 검색 결과 — 영업중 기본 필터
- 검색 결과 목록은 **기본적으로 영업중(status=open)만** 표시한다.
- 결과 상단에 토글/체크박스: "폐업 병원도 보기" (기본 꺼짐). 켜면 closed도 포함.
- 폐업 병원은 켰을 때도 회색 처리 유지(빨강은 폐업 배지에만, CLAUDE.md 색상 규칙).
- 주의: 이 필터는 검색 결과 목록에만 적용. 병원 상세의 "동일 주소 타임라인"에는 폐업 기록이 그대로 나와야 함(핵심 기능이므로 절대 필터링하지 말 것).

## 2. 지역 선택 (전국 대응 필수)
- 전국이 되면서 지역 선택 기능이 필요하다. 앱에 "지역" 개념 추가:
  - 홈 상단 또는 검색 화면에 현재 선택된 지역 표시 + 변경 버튼 (예: "인천 남동구 ▾")
  - 지역 선택 화면/바텀시트: 시/도 목록 → 선택 시 시군구 목록. 데이터의 sido/sigungu 필드에서 실제 존재하는 값만 동적으로 추출해 목록 구성(하드코딩 금지).
  - "전체" 옵션도 제공(특정 시군구로 안 좁히고 전국/시도 전체 검색).
- 선택한 지역은 앱 전역 상태(Riverpod provider)로 유지하고 SharedPreferences에 저장(앱 재실행 시 복원).
- 검색·주변 목록은 선택된 지역으로 1차 필터링. (지역 미선택 시 기본값: GPS 있으면 현재 위치 기반 시도, 없으면 '전체' 또는 첫 진입 시 지역 선택 유도.)

## 3. GPS 위치 + 내 주변
- 패키지: geolocator (권한: android fine/coarse location, AndroidManifest 추가)
- 위치 권한은 앱 시작 시가 아니라 "내 주변 병원" 버튼/탭 최초 사용 시 요청 (CLAUDE.md 원칙).
- 권한 허용 시: 현재 좌표 기준 거리 계산 → "가까운 순" 정렬 활성화. 병원 카드에 거리(예: 1.2km) 표시.
  - 거리 계산은 좌표(lat/lng) 있는 병원만 가능. **좌표 null인 병원은 거리 미표시("거리 정보 없음")하되 목록에서 제외하지는 말 것** (검색·상세는 정상 제공).
- 권한 거부 시: 거리/가까운 순 없이 지역 선택 기반으로만 동작. 거부해도 앱은 완전히 사용 가능해야 함.
- 정렬 옵션 유지: 가까운 순(위치 있을 때)/운영 기간 긴 순/최근 개원 순/이름 순. ('신뢰도 순' 등 금지 — CLAUDE.md)

## 4. 두 방식 공존 UX
- 지역 직접 선택과 GPS "내 주변"은 함께 제공한다:
  - 위치 권한 있으면: 기본 "내 주변"(현재 위치 시군구 자동 선택 + 가까운 순)
  - 위치 권한 없거나 거부: 사용자가 고른 지역 기준
  - 사용자가 지역을 수동 선택하면 그 선택이 GPS보다 우선(명시적 선택 존중)

## 5. 성능 (전국 1만 건)
- 번들 로드/검색이 전국 규모에서도 버벅이지 않게: 검색은 소문자·공백 정규화 후 contains, 필요 시 첫 로드 때 인덱스(예: 지역별 그룹 맵) 1회 구성해 재사용.
- 초기 로딩 인디케이터 표시(번들 파싱 중).
