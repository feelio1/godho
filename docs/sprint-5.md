# 스프린트 5 지시서 — 펫병원체크 지도(카카오맵) + 애드몹 광고

목표: (1) 네이버 지도를 **카카오맵**으로 교체하고 지오코딩된 좌표로 병원 마커 표시, (2) 애드몹 **하단 고정 배너**(전역 상시) + **앱 오프닝 광고**(빈도 제한) 통합.

전제: hospitals.json에 좌표가 대부분 채워짐(지오코딩 완료, 좌표 없는 병원 약 347곳 잔존). CLAUDE.md 원칙·워딩·색상 준수. Riverpod 유지. 기능 로직(검색·필터·타임라인·병합) 변경 금지.

키/ID는 코드에 하드코딩하지 말고 `--dart-define` 또는 별도 설정 파일(gitignore 처리)로 주입받는 구조로. 지시서에는 placeholder로 표기하고, 실제 값은 사용자가 로컬에서 넣는다.

---

## 1. 카카오맵으로 지도 교체
- 기존 flutter_naver_map 관련 코드/의존성 제거. 카카오맵 Flutter SDK(kakao_map_plugin 등 적절한 패키지)로 교체.
- 카카오 **네이티브 앱 키**로 초기화. AndroidManifest에 키 등록 필요(placeholder: `KAKAO_NATIVE_KEY`).
- "주변 병원" 탭에서만 지도 로드(기존 설계 유지, 비용 방어).
- 지도에 좌표(lat/lng) 있는 병원 마커 표시:
  - 마커 색/구분: 영업=기본, 신규 개원=회색, 상태확인필요=옅은색 (CLAUDE.md 색상 규칙, 신뢰도 색 금지)
  - **좌표 null인 병원(약 347곳)은 마커에서 제외**하되 목록·검색·상세에는 정상 표시.
  - 마커 탭 → 하단 카드(병원명, 영업상태, 운영기간, 동일주소기록, 거리[가능시], 상세보기·비교추가).
- 지도 진입 시 위치 권한 요청(앱 시작 시 아님, 기존 원칙). 권한 있으면 현재 위치 중심, 없으면 선택 지역 중심.
- 키 미설정 시: 기존처럼 "지도 준비 중" 스텁으로 안전하게 폴백(빌드/실행이 키 없이도 되게).

## 2. 애드몹 하단 고정 배너 (전역 상시)
- google_mobile_ads 패키지 사용. 앱 전역 하단(하단 탭 바 위)에 배너 상시 노출.
- 홈·검색·상세·저장·주변 모든 화면에서 노출되되, **콘텐츠를 가리지 않게**(하단 고정, 데이터 영역과 겹치지 않음).
- 병원 상세의 타임라인·진료비 등 데이터 카드 위에 겹치지 말 것.
- App ID: placeholder `ADMOB_APP_ID` (AndroidManifest 등록). 배너 광고 단위 ID: placeholder `ADMOB_BANNER_UNIT_ID`.
- 광고 로드 실패 시 배너 영역이 빈 채로 깔끔하게 처리(레이아웃 깨짐 없이).

## 3. 애드몹 앱 오프닝 광고 (빈도 제한)
- 앱 오프닝 광고 단위 ID: placeholder `ADMOB_APP_OPEN_UNIT_ID`.
- 표시 시점: 앱을 포그라운드로 가져올 때(콜드 스타트 또는 백그라운드 복귀). 단 아래 안전장치 필수:
  - **빈도 제한: 마지막 노출 후 4시간 이내에는 다시 표시하지 않음.**
  - 광고가 미리 로드 완료된 경우에만 표시(로드 안 됐으면 그냥 넘어가고 앱 정상 진입).
  - 첫 설치 직후 첫 진입, 앱 로딩(번들 파싱) 중에는 억지로 띄우지 말 것 — 앱이 버벅이지 않게.
  - 사용자가 광고 닫으면 정상적으로 원래 화면 진입.
- 애드몹 정책 준수: 예기치 않게 콘텐츠 가리지 않기, 과도한 노출 금지.
