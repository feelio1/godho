스프린트 13 지시서 — 펫병원체크 색상 개편(블루) + 홈 보강 + 뒤로가기 버그

목표: (1) 흐릿한 파스텔 민트 → 확실하고 신뢰감 있는 블루 계열로 색상 개편, (2) 홈 화면을 병원 카드 리스트 중심으로 보강(허전함 개선), (3) 뒤로가기 시 앱 종료 버그 수정. 데이터/검색/타임라인 로직은 변경 금지 — 색·레이아웃·표시만. CLAUDE.md 원칙·중립성 준수.

1. 색상 개편 (파스텔 민트 → 블루)

* `lib/theme/app_colors.dart`만 수정(app_theme.dart는 전부 토큰 참조라 손댈 필요 없었음):
  - primary 0xFF6FA98A(세이지 그린) → 0xFF2563EB(딥블루), primaryDark 0xFF1D4ED8, primarySoft 0xFFDBEAFE.
  - textPrimary 0xFF4A3F35(따뜻한 회갈색) → 0xFF1F2937(진한 회색/네이비), textSecondary/textCaption도 같은 계열의 쿨그레이로.
  - 배경 0xFFFAFBF6(옅은 웜톤) → 0xFFF8FAFC(아주 옅은 회색), surfaceLight는 순백 유지 — 카드가 배경 대비 또렷이 도드라지게.
  - 상태색: `open`을 0xFF16A34A(그린)로, `closed`/`neutral`을 쿨그레이 0xFF6B7280으로 — 지시서대로 "영업중을 굳이 블루로 하지 않음", 폐업은 여전히 회색(빨강 아님) 원칙 유지.
  - `error`(시스템 오류 전용, 폐업 배지와 분리된 값)도 선명한 빨강 0xFFDC2626으로 갱신.
* 마스코트 이미지(janggureum, marker, my_location, home_banner 등)는 전혀 건드리지 않았다 — `StatusBadge`/`TimelineView`/카드/버튼이 전부 `AppColors` 토큰만 참조하므로 파일 하나만 바꿔도 전 화면이 자동으로 블루 톤이 된다.

2. 홈 화면 보강 (병원 리스트 중심)

* `lib/screens/home_screen.dart`를 다음 순서로 재구성했다: 검색창 → 배너(축소) → 지정 병원(있을 때) → "지도에서 보기" 버튼 + 지역 표시 → **내 주변 가까운 병원**(신규, 세로 카드 5개 + "전체 병원 보기") → **운영 20년 이상 병원**(신규) → **최근 개원한 병원**(신규) → 최근 확인한 병원(신규 — 기존엔 탭 안에 숨어 있던 것을 독립 섹션으로) → 저장한 병원(기존 유지).
* 기존에 있던 "병원 둘러보기" 탭 전환식 캐러셀(가까운 순/오래된 순/최근 개원 순/최근 확인 — 하나만 골라서 보는 방식)을 걷어내고, 그 네 가지를 전부 동시에 보이는 독립 섹션으로 풀어냈다 — 이번 지시서가 명시한 홈 구성과 "허전함 개선" 목표에 맞춘 결정이다. 밑에 깔려 있던 정렬 로직(`HospitalRepository.sortHospitals`, `SortOption`)은 그대로 재사용했고, 탭 전용이었던 `lib/providers/home_section_provider.dart`는 더 쓰이지 않아 삭제했다.
* 각 섹션은 해당 데이터가 비어 있으면 통째로 숨는다(`if (list.isNotEmpty)`). 제목은 전부 정렬 기준의 사실 표기뿐이다: "내 주변 가까운 병원", "운영 20년 이상 병원", "최근 개원한 병원", "최근 확인한 병원", "저장한 병원" — "추천/베스트/믿을 수 있는" 같은 평가 표현 없음.
* "내 주변 가까운 병원"은 위치가 없으면 선택 지역 기준 목록을 그대로 보여준다(`sortHospitals`가 위치 없을 때를 이미 안전하게 처리해 둠 — 거리 정렬만 의미가 없어질 뿐 지역 필터는 그대로 적용됨). 카드는 기존 `HospitalCard`(스프린트 10에서 이미 썸네일·주소·거리·상태 배지를 갖춘 위젯)를 그대로 재사용했다.
* 광고·커머스·포인트샵·쿠폰·평점·추천 배너는 추가하지 않았다 — 하단 고정 애드몹 배너만 기존대로 유지.

3. 뒤로가기 네비게이션 버그

* 진단: `Navigator.push`로 올라간 화면(상세 등)은 원래도 정상적으로 pop되어 이전 화면으로 돌아간다(별도 수정 불필요, 코드 검토로 확인). 진짜 문제는 하단 탭 자체(`MainShell`)가 앱의 유일한 루트 라우트라, 탭 목록 화면(주변 병원/진료기록/저장 등, 위에 아무것도 push되지 않은 상태)에서 시스템 뒤로가기를 누르면 `Navigator.maybePop()`이 실패해 Flutter 기본 동작대로 앱이 즉시 종료됐다 — "먼저 홈 탭으로" 같은 중간 단계가 아예 없었다(`PopScope` 자체가 없었음, 지시서의 "원인 후보"와 일치).
* 수정 (`lib/screens/main_shell.dart`): `_MainShellBody`를 `ConsumerStatefulWidget`으로 바꾸고 `PopScope(canPop: false, onPopInvokedWithResult: ...)`로 감쌌다.
  - 홈이 아닌 탭에서 뒤로가기 → 홈 탭(index 0)으로 전환.
  - 홈 탭에서 뒤로가기 → "한 번 더 누르면 종료됩니다" 스낵바, 2초 안에 다시 누르면 `SystemNavigator.pop()`으로 종료.
  - 이 `PopScope`는 `MainShell`의 라우트가 스택 최상단일 때만 개입한다 — 상세 등 push된 화면이 위에 있으면 그 화면이 먼저 pop되므로 "상세→뒤로=목록/이전" 동작은 그대로다.

하지 말 것 (준수 확인)

* 데이터/검색/필터/타임라인/병합/지도 로직 — 미변경(건드린 파일은 theme·home_screen·main_shell·home_banner뿐).
* 광고·커머스·포인트샵·쿠폰·병원 유료 노출/추천 배너 — 추가 없음.
* 병원 평점·별점·후기 — 추가 없음(외부 리뷰 링크만 기존 유지).
* "추천/인기/베스트/믿을 수 있는" 등 평가·서열 표현, 오래됨=좋음 프레이밍 — 없음("운영 20년 이상 병원"처럼 기준만 표기).
* 마스코트 이미지 교체 — 없음(파일 자체는 전혀 건드리지 않음).

## 실기기 확인 권장 항목

* 상세 화면에서 뒤로가기 → 원래 목록/홈으로 돌아오는지.
* 주변 병원/진료기록/저장 탭에서 곧장 뒤로가기 → 홈 탭으로 전환되는지(앱이 바로 꺼지지 않는지).
* 홈 탭에서 뒤로가기 → 스낵바 안내 → 2초 안에 다시 누르면 종료, 시간이 지나면 다시 안내부터 시작하는지.

## 구현 메모

- `PopScope`는 `canPop: false`로 고정해 두고 `onPopInvokedWithResult`에서 직접 판단한다 — `didPop`이 이미 true면(다른 경로로 이미 pop된 경우) 아무 것도 하지 않고 그대로 반환한다.
- 홈의 "병원 둘러보기" 탭(가까운 순/오래된 순/최근 개원 순/최근 확인)을 지우면서 `home_section_provider.dart`도 함께 삭제했다 — 남겨두면 쓰이지 않는 provider가 되어 혼동을 준다. 정렬 자체를 담당하던 `HospitalRepository.sortHospitals`/`SortOption`(스프린트 2~4에서 만든 검색 로직)은 전혀 손대지 않고 홈에서도 그대로 재사용했다.
- `test/widget_test.dart`에 새 홈 섹션 제목을 확인하는 assertion을 추가했다. 아래쪽 섹션은 초기 뷰포트 밖이라 `tester.scrollUntilVisible`로 스크롤한 뒤 확인한다.
