# 스프린트 3 지시서 — 펫병원체크 디자인 정비

목표: 기능은 그대로 두고 **비주얼 톤 정비 + 마스코트(장구름) 자리 마련 + 예약 버튼 자리(준비중 처리)**. 기능 로직은 건드리지 말 것.

전제: 스프린트2까지 완료(전국·지역선택·필터). CLAUDE.md 원칙·워딩 준수. 기존 화면 구조·라우팅·상태관리(Riverpod)는 유지하고 스타일링만 개선.

---

## 디자인 방향
- 콘셉트: "친근하지만 데이터는 신뢰감 있게." 토스/카카오뱅크처럼 캐릭터로 따뜻함을 주되, 병원 데이터(타임라인·진료비·상세)는 깔끔하고 또렷하게.
- **컬러**: 민트/청록 베이스 + 포인트 색 1개(코랄 또는 옐로우). 중립 회색 계열로 정보 위계.
  - 예: primary 청록/민트, accent 코랄, 영업=초록, 폐업=회색(빨강은 폐업 배지/오류만), 신규=회색 중립.
  - 색을 코드 전역에서 재사용하도록 theme(AppColors/ThemeData)에 토큰으로 정의. 하드코딩 색값 흩어지지 않게.
- **타이포**: 제목/부제/본문/캡션 위계 명확히. 병원명은 크고 굵게, 메타정보는 작고 연하게.
- **모양**: 둥근 모서리 카드, 은은한 그림자 또는 얇은 테두리로 카드가 배경과 또렷이 구분되게. 현재 너무 휑한 여백을 정보 밀도 있게 조정.
- 과한 장식 금지, 데이터 가독성 우선.

## 마스코트(장구름) 자리 마련
- 마스코트: 흰 비숑 캐릭터 "장구름". **실제 이미지 파일은 아직 없음** → 지금은 placeholder로 자리만 확보(임시로 원형 도형/아이콘/이모지 등 가벼운 것). 나중에 asset 이미지로 교체 가능하게 위젯으로 분리(MascotImage 위젯 같은 것, 경로만 갈면 되도록).
- 등장 위치(친근함 담당, 정보 영역엔 넣지 말 것):
  - 홈 상단 인사 영역 (예: 장구름 + "동물병원 방문 전, 확인해보세요")
  - 빈 상태: "저장한 병원이 없습니다", 검색 결과 없음 → 장구름 + 안내문
  - 로딩(번들 파싱 중), 지도 준비중 화면
- 병원 상세의 데이터 카드·타임라인 영역엔 캐릭터 넣지 말 것(신뢰감 유지).

## 예약 버튼 자리 (준비중 처리)
- 병원 상세 화면 액션 영역에 "예약" 버튼 추가(전화/길찾기/비교/공유와 나란히 또는 하단).
- 누르면 실제 예약 기능 대신 "준비 중입니다" 안내(스낵바 또는 바텀시트). 지도 준비중과 동일 패턴.
- 목적: 향후 외부 예약 연결(전화/네이버예약 링크)을 붙일 UI 자리 확보. 지금은 어떤 병원과도 거래 관계 없음(중립성 유지). 문구는 평가/영업색 없이 중립적으로.
