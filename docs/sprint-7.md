스프린트 7 지시서 — 펫병원체크 지도 마커/클러스터/내 위치 개선

목표: 스프린트 6에서 넣은 지도 마커·클러스터·내 위치의 실사용 문제 3가지 수정. nearby_map 화면과 클러스터링 로직만 수정, 데이터/검색/타임라인 로직은 변경 금지.
전제: 카카오맵 정상 표시, 마커/클러스터/내위치 기본 구현됨(스프린트 6). CLAUDE.md 중립성·워딩 준수.

1. 내 위치 마커: 마스코트로 교체

* 파란 점 → 마스코트(장구름) 자리로 교체. 실제 이미지가 아직 없어 후광(halo) placeholder를 쓰고, 병원 마커와 asset 경로를 분리해 두어 나중에 이미지 하나만 교체하면 된다.

2. 핵심 버그: 줌아웃 시 클러스터(N)조차 사라짐

* 원인 점검 결과, 순수 클러스터링 함수(`clusterHospitals`) 자체는 모든 줌에서 병원을 빠짐없이 그룹화하도록 이미 보장되어 있었다(단위 테스트로 확인). 실사용에서 보고된 증상은 화면(`_renderMarkers`) 쪽의 두 가지 약점이 원인일 가능성이 높았다:
  - 기존 마커를 지우고 새로 그리는 도중 POI 하나(이미 사라졌거나 일시적 오류)가 실패하면 전체 갱신이 중단되어, 그 줌에서 지도가 빈 채로 남을 수 있었다.
  - 빠른 핀치줌처럼 짧은 시간에 `onCameraMoveEnd`가 겹쳐 호출되면 재진입 가드가 나중 요청을 그냥 버렸다 — 마지막 줌 상태가 반영되지 않고 이전 상태로 멈출 수 있었다.
* 격자 크기 공식도 줌이 일정 이하로 내려가면 더는 커지지 않는 상한이 있어, "멀수록 더 크게 묶인다"는 기대와 어긋났다.

3. 개별 마커가 너무 늦게 나타남

* 클러스터 해제 줌(`_clusterDisabledZoom`)과 이름 라벨 줌(`_labelZoomThreshold`)이 둘 다 지나치게 높았다(17, 16 — 기본 시작 줌 15보다도 높음).

수정 내용

* `lib/screens/nearby_map_screen.dart`
  - `_buildMyLocationStyle` — 파란 점 대신 후광 + 마스코트 자리 아이콘(`_myLocationHaloBytes`)으로 교체. 실제 이미지는 `assets/mascot/my_location.png`에 넣으면 코드 변경 없이 자동 적용.
  - `_renderMarkers` — 기존 POI 제거/새 POI 추가를 각각 개별 try/catch로 감싸, 하나가 실패해도 나머지는 계속 그려지도록 함. 재진입 가드는 "겹치면 버림" 대신 "겹치면 기억했다가 끝난 직후 한 번 더 실행"으로 바꿔, 연속된 줌 변경의 마지막 상태가 항상 반영되게 함.
  - `_clusterDisabledZoom`: 17 → 14, `_labelZoomThreshold`: 16 → 14(같은 값으로 통일 — 개별 마커가 보이는 순간 이름도 함께 보임).
* `lib/utils/map_clustering.dart`
  - `cellSizeForZoom` 공식을 상한 없이(안전 상한만 넉넉히 24단계) 계속 커지도록 재작성 — 줌아웃할수록 격자가 끊김 없이 계속 커져, 어느 줌에서도 클러스터(또는 개별 마커)가 반드시 보인다.
  - 성장 배율을 2배 → 1.7배로 완만하게 조정해 줌 단계 사이 전환이 덜 급격하도록 함.
* `test/map_clustering_test.dart`
  - `clusterDisabledZoom` 기본값 변경(17→14)에 맞춰 기존 테스트 값 갱신.
  - 새 불변식 테스트 추가: "disabled zoom 아래 모든 줌에서 격자 크기가 계속 커지고 0이 되지 않는다", "극단적으로 줌아웃해도(음수 줌 포함) 결과가 비지 않고 모든 병원을 포함한다" — 완료 기준 2번을 알고리즘 단에서 회귀 방지로 고정.

## 구현 메모

- `PoiStyle.zoomLevel`/`addStyle`는 "스타일의 zoomLevel 값이 카메라의 현재 zoomLevel보다 작을 때 그 스타일이 적용"되는 방식이라, 라벨 줌 게이팅 자체(문턱보다 확대해야 노출)는 스프린트 6 구현이 맞았다. 실사용 버그는 라벨 로직이 아니라 클러스터/마커 다시 그리기(`_renderMarkers`)의 오류 전파와 재진입 처리 쪽에 있었다.
- 순수 클러스터링 함수는 "어떤 줌에서도 결과가 비지 않는다"는 불변식을 단위 테스트로 명시적으로 고정해 뒀다 — 이 환경엔 실기기가 없어 화면에서 직접 재현·확인은 못 했지만, 알고리즘 차원의 회귀는 테스트가 계속 잡아준다.
- 내 위치 halo placeholder는 병원 마커의 `_circleBytes`(단색 원 + 흰 테두리)와 달리 바깥에 반투명 원을 하나 더 둘러, 지도 위에서 "유일한 내 위치 지점"임을 형태만으로도 구분할 수 있게 했다.
