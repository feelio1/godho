스프린트 14 지시서 — Petcli 디자인 전면 적용

목표: 확정된 새 디자인 시안(색·타이포·간격·컴포넌트 토큰 스펙 + 화면별 구성)을 실제 앱에 반영한다. 기능/데이터/상태관리/로직은 전혀 바꾸지 않는다 — 화면 스타일링·레이아웃·컴포넌트 구조만 교체. 브랜드명을 "펫병원체크"에서 "Petcli"로 바꾸되, 지금은 텍스트로 표시하고 나중에 로고 이미지로 교체할 수 있게 분리된 위젯으로 만든다.

**중요 — 이미지 시안 관련 고지**: 이번 스프린트 지시서에는 "첨부 화면 18종"이 언급되었지만, 실제로는 텍스트로 된 디자인 토큰·컴포넌트·화면별 스펙만 전달되었고 이미지 자체는 이 세션에서 확인되지 않았다. 아래 구현은 모두 그 텍스트 스펙을 기준으로 했다 — 실제 이미지와 미세하게 다를 수 있으니 시각적으로 한 번 검토해 주길 권장한다.

1. 디자인 토큰

* `lib/theme/app_colors.dart` 전면 재정의: 브랜드 블루(`#2563EB`/`#1D4ED8`/텍스트용 `#1E40AF`), 액센트 틴트 `#EAF1FE`, 페이지 배경 `#F1F5F9`/카드 `#FFFFFF`/인풋 인셋 `#F1F5F9`, 텍스트 4단계(제목/라벨/보조/placeholder), 보더 3단계, 상태색을 bg/text/dot 3분할로 새로 정의(영업중=그린, 폐업·정보부족=회색 — 빨강은 시스템 오류 전용, CLAUDE.md 원칙 그대로).
* `lib/theme/app_dimens.dart`(신규): `AppSpacing`/`AppRadius`/`AppShadows` + `appCardDecoration()` 헬퍼.
* `lib/theme/app_theme.dart`: Gothic A1 타이포 체계(제목 22–27/w900 ~ 보조 11–12/w500), 카드/칩/인풋/버튼/세그먼트/내비게이션바/날짜·시간피커 컴포넌트 테마 전면 재정의.
* **Gothic A1 폰트 번들링 방식 변경**: 처음엔 `google_fonts` 패키지로 붙였으나, 이 패키지는 기본적으로 폰트 파일을 **런타임에 네트워크로 내려받는다** — CLAUDE.md의 "정적 JSON 번들 로드, 서버 없음" 오프라인 우선 구조와 맞지 않고, 실제로 테스트 환경에서 네트워크 페치 실패 로그가 확인됐다. `assets/fonts/`에 Gothic A1 6종 굵기(400/500/600/700/800/900)를 정적으로 번들링하고 `pubspec.yaml`의 `fonts:` 항목으로 등록하는 방식으로 바꿨고, `google_fonts` 의존성은 제거했다. 앱 용량이 폰트만큼(약 13MB) 늘었지만 오프라인에서도 항상 같은 폰트로 렌더링된다.

2. 공용 컴포넌트

* `StatusBadge`: 알파 블렌딩 대신 시안이 지정한 고정 bg/text/dot 색.
* `HospitalAvatar`(신규): 건물 아이콘 + 틴트 배경. 스프린트 10의 사진 placeholder(`HospitalThumbnail`, 실제 병원 사진 없이 고정 이미지만 보여주던 위젯)를 대체 — 모든 병원이 같은 아이콘을 쓰므로 "이 병원이 더 낫다"는 인상을 주지 않는다. `HospitalThumbnail` 사용처(병원 카드/지정 병원 카드/지도 바텀시트)를 전부 옮기고 파일 자체는 삭제했다. 상세 화면의 160px 히어로 배너는 새 상세 화면 시안에 없어 제거했다.
* `HospitalCard`: 아바타 + 상태 pill + 메타 한 줄(개설일·운영기간·거리·동일주소기록) + "진료비 준비 중" 회색 칩 + trailingIcon(기본 chevron, 저장 화면은 채워진 북마크). 폐업 카드는 `AppColors.closedCardBg` 배경 + 옅은 보더로 가라앉힌다.
* `SearchSetCard`(신규): 흰 카드 위 회색 인셋 검색 필드 + 가로 스크롤 지역 칩. 지역 칩은 `HospitalRepository.sidoList`(데이터에서 뽑은 실제 시/도 목록)로 채우고, 활성 칩만 액센트+핀 아이콘(+caret, 시/도 칩만)으로 강조한다. 탭하면 기존 `regionProvider.selectRegion`을 그대로 호출 — 새 지역 상태/데이터 없음. 홈·검색결과 화면이 공유한다.
* `MascotMessage`(빈 상태 공용 컴포넌트): 112px 원형 틴트 배지 + 선택적 우하단 상황 아이콘(`overlayIcon`) + 제목 18/w800 + 안내문 13.5/w500·2줄. 기존 콜사이트는 그대로 동작하고(파라미터 추가일 뿐), 진료기록/저장/검색결과없음(지역·검색 두 경우) 4곳에 상황 아이콘을 달았다.
* `FormFieldLabel`(신규): "라벨 + 회색 인셋 입력 필드" 폼 패턴 — 반려동물 등록/예약알림/진료기록추가 폼이 공유.
* `PickerSheetChrome`(신규): 그랩바 + 제목 + X 닫기 버튼 바텀시트 뼈대.
* `BrandMark`(신규): "Petcli" 텍스트 위젯 — 나중에 로고 이미지로 바꿀 때 이 위젯 내부만 고치면 된다.
* `GlobalBannerAd`: 병원 카드와 구분되는 "광고" 라벨 추가(광고 로딩·표시 로직은 그대로).

3. 화면별 반영

* **홈**: 브랜드 헤더(Petcli + "동물병원의 공개된 행정·가격 정보를 확인하세요") → 검색 세트 카드 → 배너 → 지정 병원 → 지도에서 보기 → 내 주변 → 오래 운영된 병원(20년+) → 최근 개원 → 최근 확인 → 저장한 병원. 정렬/필터 데이터 로직(스프린트 13)은 그대로.
* **검색결과**: 상단을 검색 세트 카드로 교체, 폐업 포함 토글·정렬 칩은 그대로.
* **병원상세**: 타임라인 노드 색을 "영업상태"가 아니라 "가장 최근 기록인지"로만 구분(현재=파란, 과거=회색) — 폐업 여부와 시간축이 섞여 평가처럼 읽히지 않게 분리. 외부 링크 섹션에 "Petcli는 평가·별점을 자체적으로 제공하지 않습니다" 고지 추가. 히어로 배너 제거(위 참고).
* **진료기록**: 기존 구조(반려동물 카드+요약+진료기록/예약알림 탭)가 이미 토큰 기반이라 테마 갱신만으로 새 톤 반영.
* **반려동물등록**: `FormFieldLabel` 적용, 생일 선택 시 화면에서만 계산하는 나이 표시 추가(저장 필드 아님). **갭**: 시안의 "성별·중성화(토글)"·"체중" 필드는 `Pet` 모델에 해당 필드가 없어(모델 변경 금지) 이번 스프린트에서 생략했다. **갭**: "품종(검색+리스트) 피커"도 실제 품종 데이터셋이 없어 자유 입력 텍스트 필드로 유지했다.
* **예약알림**: 방문 목적 칩(자주 쓰는 문구를 눌러 기존 자유입력 `reason` 필드를 채우는 단축 입력, 모델 변경 없음) + 저장 전 미리보기 배너 추가. 병원 검색·알림 추가 로직은 그대로.
* **저장**: 전체/영업중/폐업 화면 필터 세그먼트(로컬 위젯 상태로만 구현, `savedHospitalsProvider`는 그대로) + trailingIcon으로 채워진 북마크.
* **지도**: 내 위치 마커를 스프린트 7의 마스코트 후광 placeholder에서 표준 파란 점으로 되돌렸다(시안 "내 위치(파란 점)"). 상단에 (탭하면 검색 화면으로 이동하는) 검색바 + 목록 버튼 추가 — 목록은 새로 만들지 않고 기존 검색결과 화면을 재사용한다. 바텀시트 카드 아바타·타이포 교체. 마커/클러스터링 로직은 전혀 손대지 않음.
* **진료기록추가**: `FormFieldLabel` + 인셋 필드 패턴 적용.
* **바텀시트 피커**: 지역 선택을 기존 화면 전환형(시도→시군구 순차 push)에서 좌/우 투페인 바텀시트(`showRegionPickerSheet`)로 교체(반환값·`selectRegion` 호출은 동일). 예약 알림 추가를 AlertDialog에서 같은 바텀시트 뼈대로 교체. 날짜·시간 피커는 커스텀 재구현 대신 Flutter 기본 `showDatePicker`/`showTimePicker`를 `DatePickerTheme`/`TimePickerTheme`으로 새 톤에 맞게 다시 입혔다(선택 로직 변경 없음). **범위 결정**: 정렬은 이미 칩 형태로 잘 작동하고 있어 바텀시트로 새로 바꾸지 않았고, 품종 피커는 데이터가 없어 만들지 않았다.

4. 브랜딩

* "펫병원체크"/"병원구름" 문구를 앱 전체(`main.dart` 타이틀, 홈 AppBar, 이용안내, 상세 화면 예약 안내, 공유 텍스트, `AndroidManifest.xml` 앱 라벨)에서 "Petcli"로 교체.
* `lib/utils/external_links.dart`의 공유 문구 한 줄은 "utils 디렉터리 로직 변경 금지" 범위에 있었지만, 브랜드명 문자열 교체는 로직이 아니라는 판단 하에 예외적으로 수정했다 — 다른 로직은 전혀 건드리지 않았다.

하지 말 것 (준수 확인)

* `lib/data`/`lib/models`/`lib/providers`/`lib/notifications` 디렉터리 — 이번 스프린트에서 단 한 줄도 수정하지 않았다(`git diff` 기준 확인).
* 색상 기반 병원 순위/신뢰 신호 — 없음. 폐업은 계속 회색(빨강 아님).
* 평가·추천·"베스트" 표현 — 없음.
* "영업중"을 실시간 영업 여부로 오독할 수 있는 표현 — 추가하지 않음(기존 문구 그대로).

## 알려진 갭 (다음 스프린트 후보)

* 반려동물 등록 폼의 성별·중성화·체중 필드 — `Pet` 모델 확장이 필요하다(이번 스프린트는 모델 변경 금지라 생략).
* 품종 검색+리스트 피커 — 품종 목록 데이터셋이 없다.
* CPA 네이티브 광고 카드 — 새 광고 네트워크 연동이 필요한 범위라 이번 스프린트에서는 만들지 않았고, 기존 AdMob 배너에 "광고" 라벨만 더했다.
* 정렬 바텀시트 — 기존 칩 UI가 이미 새 토큰으로 잘 작동해 이번엔 바텀시트로 바꾸지 않았다.
