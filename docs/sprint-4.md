# 스프린트 4 지시서 — 펫병원체크 목록 UX 개선

목표: (1) 검색 화면 첫 진입 시 지역 기준 병원 목록을 바로 표시, (2) 홈 병원 섹션에 보기 기준 탭 추가. 기능(데이터·필터·타임라인) 로직은 유지하고 목록/정렬 UX만 개선.
전제: 스프린트3까지 완료. CLAUDE.md 원칙·워딩·색상 준수. Riverpod 유지. 전국 번들.

## 1. 검색 화면 — 검색어 없이도 목록 표시

* 현재: 검색어를 입력해야 결과가 나옴. 지역·정렬 UI는 있으나 목록이 비어 있음.
* 변경: 검색 화면 진입 시 선택된 지역의 병원 목록을 바로 표시한다.
   * 검색어 비어 있음 → 선택 지역(시/도·시군구) 병원 전체를 정렬 기준대로 표시.
   * 검색어 입력 → 그 목록에서 병원명·주소 contains 필터링.
* 기본 필터: 영업중만(status=open) 유지. 기존 "폐업도 보기" 토글 그대로 적용.
* 성능: 지역 병원이 많을 수 있으므로(예: 서울 강남구 수백 곳) 리스트는 ListView.builder 등 지연 렌더링. 첫 프레임 지연 시 로딩 인디케이터.
* 지역 미선택 시: GPS 있으면 현재 위치 시군구, 없으면 사용자에게 지역 선택 유도 또는 시도 전체 목록(과다하면 상단 안내 + 지역 좁히기 유도).

## 2. 홈 병원 섹션 — 보기 기준 탭

* 현재: 홈의 병원 리스트 섹션이 "최근 확인한 병원"으로 자동 고정.
* 변경: 섹션 상단에 보기 기준 탭(칩/세그먼트)을 두고 사용자가 전환. 기준:
   * 가까운 순 (기본값 자리 확보, 단 위치 기능 미완성이므로 지금은 비활성/placeholder 처리: 탭은 보이되 위치 권한·좌표 준비 전까지는 "위치 준비 중" 또는 자동으로 다른 기준으로 대체)
   * 오래된 순 (운영 기간 긴 순, continuousSince 기준)
   * 최근 개원 순 (openDate 최신)
   * 최근 확인한 병원 (사용자가 상세 열람한 이력)
* 위치 기능 완성 전 기본 동작: '가까운 순'을 기본 탭으로 두되 위치 없으면 '최근 개원 순'으로 자동 폴백(또는 '가까운 순' 탭 비활성 + '최근 개원'을 기본 선택). 사용자에게 혼란 없게 처리.
* 각 항목 카드는 기존 검색 결과 카드 스타일 재사용(영업 배지, 운영기간, 동일주소 기록 수, 거리[가능 시]).
* '최근 확인한 병원'은 기존 로직 유지(SharedPreferences 등에 저장된 열람 이력).

## 하지 말 것

* 데이터·타임라인·병합 로직 변경. 상세 화면 타임라인의 폐업 기록 필터링 금지(CLAUDE.md).
