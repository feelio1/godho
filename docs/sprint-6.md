스프린트 6 지시서 — 펫병원체크 지도 개선 (마커·클러스터·내 위치)
목표: "주변 병원" 카카오 지도의 사용성 개선. (1) 마커를 캐릭터 이미지 + 병원 이름 라벨로, (2) 색 구분 제거(중립), (3) 마커 클러스터링, (4) 내 위치 표시 + "내 위치로 이동" 버튼. 데이터·검색·타임라인 로직은 변경 금지, 지도 화면(nearby_map)만 개선.
전제: 카카오맵 정상 표시됨(키·키해시 인증 완료). 좌표 있는 병원만 마커 대상(좌표 null은 기존대로 제외). CLAUDE.md 원칙·워딩·중립성 준수. Riverpod 유지.
1. 마커: 캐릭터 이미지 + 이름 라벨

* 현재 색칠된 원형 마커를 마스코트(장구름) 캐릭터 이미지 마커 + 병원 이름 라벨로 교체.
* 마스코트 실제 이미지는 아직 없음 → 기존 `MascotImage` 위젯/asset 경로 방식과 동일하게, 마커 이미지도 asset 하나만 교체하면 바뀌도록 분리(예: `assets/mascot/marker.png` placeholder, 지금은 임시 이미지/도형, 나중에 장구름으로 교체). 코드에 캐릭터를 그려 박지 말 것.
* 마커 아래(또는 옆)에 병원 이름 라벨 표시. 라벨은 일정 줌 레벨 이상으로 확대했을 때만 노출(줌 아웃 상태에선 라벨 숨김 — 겹침 방지).

2. 색 구분 제거 (중립 원칙)

* 영업=초록 / 신규=회색 등 상태별 색 구분 제거. 모든 병원을 동일한 마커로 표시.
* 이유: 색이 병원 등급/판정으로 오해될 수 있어 CLAUDE.md "평가 금지" 원칙에 어긋남.
* 영업 상태·신규 여부 등은 마커 탭 시 하단 카드/상세에서 팩트로 제공(기존 하단 카드 유지). 지도 위 색으로 표현하지 않음.

3. 마커 클러스터링

* 줌 아웃 시 마커가 겹쳐 뭉치는 문제 해결. 가까운 마커들을 클러스터로 묶어 "N" 개수 표시.
* 확대하면 클러스터가 개별 마커로 풀리고, 개별 마커엔 이름 라벨 노출.
* 카카오맵 SDK의 클러스터링 기능(LabelLayer/클러스터 API 등) 활용. 성능 위해 화면 영역(bounds) 내 마커 위주 렌더 유지.

4. 내 위치 표시 + 이동 버튼

* 위치 권한 허용 상태에서 지도에 현재 위치 표시(파란 점 등 표준 표기).
* 지도 우하단에 "내 위치로 이동" 버튼(원형 FAB, 위치 아이콘). 탭하면 현재 위치로 카메라 이동 + 적절한 줌.
* 위치 권한 없거나 위치 못 얻으면: 버튼은 보이되 탭 시 권한 요청/안내. 앱은 정상 동작(선택 지역 중심).
* 최초 진입 시 위치 있으면 현재 위치 중심으로 시작(기존 동작 유지·보강).

하지 말 것

* 데이터/검색/필터/타임라인/병합 로직 변경.
* 마커 색으로 상태·신뢰도 표현(중립 원칙).
* 좌표 없는 병원을 억지로 지도에 올리기.
* 마스코트/캐릭터를 코드에 하드코딩(asset 교체 방식 유지).
* CLAUDE.md 워딩·색상·중립성 위반.

## 구현 메모

- kakao_map_sdk(1.2.6, 1.3.0 확인)에는 네이티브 클러스터 API가 없어
  `lib/utils/map_clustering.dart`에서 줌 레벨에 따라 격자 크기를 바꿔가며
  가까운 병원을 직접 묶는 방식으로 구현했다(순수 Dart 함수라 위젯/SDK 없이
  단위 테스트 가능 — `test/map_clustering_test.dart`).
- 병원 이름 라벨의 줌 게이팅은 SDK가 제공하는 `PoiStyle.addStyle(zoomLevel: ...)`
  기능을 그대로 활용했다(줌 레벨별로 다른 스타일을 자동 적용) — 카메라 이동마다
  직접 다시 그릴 필요가 없어 더 가볍다.
- "내 위치" 표시는 SDK에 별도 기능이 없어, 표준 파란 점 아이콘을 생성해 별도
  POI로 얹고 위치가 갱신될 때마다 다시 그리는 방식으로 구현했다.
- 화면 영역(bounds) 필터링은 이번 스프린트 범위에서는 생략했다 — 스프린트
  5에서 이미 도입한 지역 필터 + 300개 상한이 기존 안전장치 역할을 하고,
  클러스터링이 추가되며 화면에 실제로 그려지는 마커 수 자체가 크게 줄어
  체감 성능 이슈가 낮다고 판단했다. 필요해지면 `KakaoMapController.getBounds()`
  (1.3.0+)로 다음 스프린트에서 보강할 수 있다.
